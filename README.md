# Algoritmos e Programação I

- Estudo das estruturas de dados fundamentais e seus algoritmos associados.

- **Objetivo:** Projetar soluções corretas e eficientes para problemas computacionais.
- **Ferramentas:** C/C++, recursao, abstração de dados, análise de complexidade.

## Pilares da Disciplina
- **Recursão:** Pensar problemas de forma auto-referente, com casos base e passos recursivos.
- **Tipos Abstratos de Dados:** Separar especificação (o que) de implementação (como).
- **Estruturas Lineares:** Listas, pilhas, filas — organização sequencial com operações especializadas.
- **Estruturas Não-Lineares:** Árvores binárias e de busca — representação hierárquica para busca eficiente.
